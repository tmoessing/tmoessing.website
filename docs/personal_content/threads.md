# Tyler Moessing - Threads

How to add a post: open it on Threads, use "Copy link", then add a block under
"Threads Posts" like the example below. Newest goes on top. The title is just a
label for you and is not shown on the page. Tags can be PICKS, PROJECTS or DEV
(comma separated for more than one). Anything above the first section is ignored.

Example:
### Shipped the meal planner
link: https://www.threads.com/@tmoe.builds/post/ABC123xyz
tags: PROJECTS, DEV
